## Why

当前右侧趋势判断只能展示“现在”的结论，用户很难复现过去某一天系统会如何判断，也难以识别确认度变化到底领先、同步还是滞后于价格。新增历史截面复盘后，用户可以选择过去任意交易日，查看系统在当天基于当时可见数据会给出的右侧趋势判断；趋势折线图作为“证伪镜”，用后续价格轨迹和轻量前瞻标签来校准这套自由量价框架，而不是替代人工判断。

## What Changes

- 新增按历史日期计算右侧趋势报告的能力：输入 ticker 和 as-of 日期，返回截至该交易日的信号、阶段、确认度、价格上下文和分析元数据。
- 新增默认近 60 个交易日右侧趋势序列：对同一 ticker 连续计算每个交易日的右侧确认度、阶段、右侧信号数量和关键状态，供前端绘制趋势折线图。
- 趋势图采用确认度与归一化价格叠放，用于观察右侧判断是否领先、同步或滞后于价格，而不是只展示两条孤立指标线。
- 为历史截面和趋势点增加轻量前瞻结果标签，例如后 5/10/20 个交易日涨跌幅、最高涨幅和最大回撤，用于证伪和校准判断。
- 明确总确认度的语义：它代表当前结构强度，不代表准确率、胜率或上涨概率；报告需要强化左侧准备度与右侧触发度的分层解释。
- 前端分析页新增历史日期选择和复盘视图，用户可以切换“当前分析”和“历史复盘”。
- 明确防止未来数据泄漏：历史复盘中的日线、指数环境、成交密集区和 quote 展示都必须以 as-of 日期为截断点或显式标注不可用。
- 不新增买卖点、交易收益曲线、策略胜率、自动交易信号评估；本次只做人工复盘用的历史截面和证伪辅助。

## Capabilities

### New Capabilities

- `right-signal-backtest`: 右侧趋势历史截面复盘、默认近 60 个交易日趋势序列、轻量前瞻结果标签、相关 API 与前端展示契约。

### Modified Capabilities

- None.

## Impact

- `pipeline/analyzer/report.py`: 支持 `as_of` 截断、历史 report metadata、60 日右侧趋势序列、归一化价格点、轻量前瞻标签和分层解释 payload 构建。
- `pipeline/analyzer/signals.py` / `phase.py` / `narrative.py`: 复用既有信号和阶段计算规则，必要时增加可测试的输入校验，不改变公式语义。
- `pipeline/server.py`: `/api/signal-report/<ticker>` 增加 `as_of` 查询参数，新增或扩展返回字段承载历史复盘与趋势序列。
- `web/src/api.ts`, `web/src/types.ts`, `web/src/App.tsx`, `web/src/components/SignalTrendReport.tsx`: 增加日期选择、请求参数、类型定义、分层解释展示和趋势折线图。
- 测试：新增历史截断、防未来函数、趋势序列长度与排序、API 参数解析、前端关键渲染逻辑的覆盖。
