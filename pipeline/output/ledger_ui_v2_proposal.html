现状 scope-toggle 是两个按钮换底色（瞬变）。方案：白色滑块在轨道里弹簧滑动（EASE 减速入位），选中态有物理连续性。

入场/出场不对称用于：页面切换 / 卡片 / 弹层 / 提示条

法则：入场 0.22s（blur 6→0 + scale .97 + y10），出场 0.18s 且更少 blur——"出场永远比入场短"，替换现在单一的 .fade-in。

另外四条纪律（无演示但同样落地）： ① 提前占位——alert/notice 出现消失不得推挤内容（找到组件最高最宽状态，永久保留盒子，内部只动 opacity）； ② 骨架屏时序——请求 <120ms 不出骨架，出了至少停 380ms（防闪烁）；空态判定前留 220ms 宽限，避免"空一帧"； ③ 禁 animate-pulse / idle 循环——除 spinner（未知时长）外，一切动效必须由事件触发； ④ prefers-reduced-motion——信息照常到达，只跳过旅程（闪色保留、位移归零）。
