一眼结论：右列信息密度感与"账本可信感"更强，代价极小——A 级改动只动 CSS 变量与图表常量。
  • 最大收益项：涨跌色从三套并存 → 唯一一套（#16865B / #C3424F），全站涨跌语义即刻一致；
  • 气质变化项：画布从冷灰蓝 → 暖灰 #F4F5F3、阴影从"浮起" → "平贴"、柱状图去渐变，AI 味显著下降；
  • 功能补齐项：黑色总资产主卡 + 高优先级黑按钮，是现状没有的两个组件；
  • 保留不动项：绿涨红跌方向、间距体系、页面结构均与现状兼容，无需改任何业务代码。
